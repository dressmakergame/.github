In Dressmaker, a customer brings you a brief. You choose a silhouette and fabrics, draft a pattern, cut and sew the garment, then see how the finished dress meets the request. Start with Rose's librarian workwear commission and experiment with the sketchbook's bodices, sleeves, skirts and fabric combinations.

At **[Dressmaker.lol](https://dressmaker.lol/)** you can:

- Try the browser-hosted prototype without installing a desktop build.
- Follow illustrated guides to the first commission, sketchbook controls, sewing and result checks.
- Compare the browser prototype with the creators' downloadable prototype and the complete Steam release.

**Best experience:** use a desktop browser and mouse. The game files begin loading after you press Play.

> Dressmaker.lol is an independent fan-made portal. The browser player is a third-party hosted prototype; this site is not the official website of the game's creators, elyaradine and Free Lives.
